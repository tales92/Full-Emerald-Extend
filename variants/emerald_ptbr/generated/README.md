# Generated Emerald PT-BR code

This directory is populated locally by `gba_recompile` from the user's
hash-verified ROM. Generated C/C++ is ROM-derived and intentionally ignored by
Git; only this README is tracked.

```powershell
build-gbarecomp\gba_recompile.exe `
  --rom C:\caminho\para\PokemonEmerald-PTBR-Zambrakas.gba `
  --config variants\emerald_ptbr\symbols\emerald_ptbr_zambrakas.toml `
  --out variants\emerald_ptbr\generated
```
