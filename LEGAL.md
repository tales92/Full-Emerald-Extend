# Licenciamento e avisos legais

## Não existe uma licença única

Este repositório é um fork e um agregado de componentes. Tornar o código visível
no GitHub não cria uma licença única nem substitui os termos de cada parte.

| Componente | Termos conhecidos |
|---|---|
| `gbarecomp/` | PolyForm Noncommercial 1.0.0; consulte `gbarecomp/LICENSE` |
| `recomp-ui/` | MIT no upstream; consulte a licença do submódulo |
| base `EmeraldRecomp` | O upstream não apresenta licença global detectável; direitos permanecem com seus autores |
| novos arquivos Full Emerald | Disponíveis para estudo e contribuição dentro dos limites dos componentes e materiais subjacentes; nenhuma permissão sobre propriedade de terceiros é concedida |
| bibliotecas/fontes | Termos próprios nos arquivos LICENSE/NOTICE correspondentes |

Por causa da licença não comercial de `gbarecomp` e da ausência de uma licença
global no upstream EmeraldRecomp, o projeto deve ser descrito com precisão como
**código-fonte público/source-available para pesquisa não comercial**, não como
um pacote irrestrito para exploração comercial. Licenciamento comercial do
gbarecomp deve ser tratado com seu autor.

## Conteúdo que não é distribuído

- ROMs de Game Boy Advance;
- BIOS de Game Boy Advance;
- saves e save states;
- shards C/C++ gerados da ROM;
- dumps, símbolos extraídos ou traces contendo dados do jogo além da metadata
  já auditada;
- o pack binário de sprites do Pokémon Follower;
- credenciais, tokens e caminhos pessoais.

Os scripts exigem que cada usuário forneça legalmente esses inputs localmente.

respectivos titulares e são mostradas apenas para documentação. Elas não podem
ser reutilizadas como se fossem assets licenciados pelo Full Emerald.

projeto. O usuário é responsável por cumprir a legislação aplicável e usar
apenas dumps e recursos para os quais tenha autorização.

Este documento é uma descrição técnica de proveniência, não aconselhamento
jurídico.
